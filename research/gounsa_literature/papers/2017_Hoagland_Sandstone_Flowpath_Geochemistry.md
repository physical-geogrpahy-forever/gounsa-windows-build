# 이 논문을 찾은 이유
사암 산림유역에서 shallow interflow, deep groundwater, spring water, hyporheic exchange가 서로 다른 weathering signatures를 가지는지 확인하여, 고운사의 chemical weathering을 하나의 평균 water residence time으로 축약해도 되는지 검토했다.

# 핵심 결과
Garner Run stream chemistry inherits distinct geochemical signatures from different subsurface flow paths.

Main sources:
```
preferential unsaturated-zone interflow
spring water
groundwater
hyporheic exchange
```

Examples of chemically distinct reservoirs include:
- soil pore water
- shallow/intermediate groundwater
- spring water

Na/Ca and Mg/Ca patterns show that mixing among flow paths can explain stream chemistry.

The study notes that sunny-side soil porewater chemistry may reflect ET concentration and associated mineral/precipitation effects.

# 핵심 해석
```
flow path
 -> residence/contact environment
 -> mineral reaction / ion exchange / ET effects
 -> distinct water chemistry
```

Therefore:
```
single bulk drainage flux
```
is not sufficient to represent chemical weathering in a sandstone hillslope.

# 고운사에 직접 사용할 수 있는 부분
Chemical-weathering hydrology should distinguish at least:

```
shallow interflow
deep groundwater/deep flow
lateral residence / mixing
```

Hyporheic exchange itself is optional for the hillslope core.
