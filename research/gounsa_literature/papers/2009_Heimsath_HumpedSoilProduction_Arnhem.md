# 서지정보
Heimsath, A. M., Fink, D., & Hancock, G. R. (2009). The 'humped' soil production function: eroding Arnhem Land, Australia. *Earth Surface Processes and Landforms, 34*(12), 1674-1684. DOI: 10.1002/esp.1859.

# 이 논문을 찾은 이유
finite-depth maximum soil production이 실제 field cosmogenic data로 확인되는지, 그리고 forest/grass vegetation landscape에서 bare bedrock과 thin soil state 사이의 discontinuity가 존재하는지 검토했다.

# 연구 유형
- field cosmogenic nuclide study
- soil-production function measurement

# 공간 구조
- soil-mantled upland hillslopes
- bedrock outcrops and soil patches

# 적용 환경
- Arnhem Land, northern Australia
- tropical seasonal climate
- open dry forest / seasonal grassland

# 핵심 과정
- bedrock-to-soil production
- erosion
- soil thickness
- patchy bedrock exposure

# 식생 입력
explicit vegetation model 없음.

Landscape vegetation:
- open dry forest
- seasonal grasses

따라서 vegetation coefficient source는 아니다.

# 핵심 결과
soil production rate는 약:
```
H ~ 35 cm
```
soil thickness에서 peak.

또:
```
exposed bedrock
<-> ~35 cm soil
```
사이에 중간 soil thickness가 관측되지 않았다.

즉 well-defined:
```
humped soil-production function
```
의 field evidence.

# 고운사에 직접 사용할 수 있는 부분
Mode B의 중요한 field precedent:

```
P(H=0)
<
P(H=finite shallow depth)
```

가능성을 직접 지지한다.

Rossi 2026의 forested-mountain modeling 및 Pelak 2016 plant-soil feedback과 함께 보면, shallow finite-depth hump는 현재 고운사에서 강한 mandatory sensitivity다.

# 새로운 coupling이 필요한 부분
Heimsath 2009 자체는 vegetation-dependent equation을 주지 않는다.

LPJ-GUESS vegetation state가 hump amplitude/location을 변화시키는 coupling은 새롭다.
