# 서지정보
Wang, C., Li, H., Xue, S., Ma, B., Shang, Y., & Li, Z. (2023). How root and soil properties affect soil detachment capacity in different grass-shrub plots: A flume experiment. *CATENA, 229*, 107221.

# 이 논문을 찾은 이유
관목 단독과 grass-shrub 혼합군집에서 root density와 soil aggregates가 detachment에 미치는 효과를 확인하기 위해 검토했다.

# 연구 유형
- flume experiment

# 공간 구조
- plot / flume

# 적용 환경
- grass-shrub community

# 핵심 과정
- soil detachment

# 식생 입력
- RLD
- shrub/grass root distribution

# 핵심 식
RLD와 >0.25 mm aggregate content를 함께 사용한 회귀가 detachment를 설명하며 `R²≈0.80`으로 정리됨.

# 파라미터와 단위
RLD, aggregate content, depth/distance.

# 원 논문의 구현 범위
혼합군집의 root-soil interaction을 실험.

# 고운사에 직접 사용할 수 있는 부분
상층 관목과 하층 초본 root pools를 합계 하나로 뭉개지 않을 근거.

# 새로운 coupling이 필요한 부분
수치모델에 반영하면 새로운 coupling.

# 한계
수치모델 아님.
