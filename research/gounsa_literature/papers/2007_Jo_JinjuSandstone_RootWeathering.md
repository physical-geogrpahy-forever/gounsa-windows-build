# 이 논문을 찾은 이유
고운사와 같은 한국 퇴적암/사암 사면에서 수목 뿌리, 수분침투, 절리, 물리·화학풍화가 동시에 관찰된 국내 field evidence를 찾기 위해 검토했다.

# 연구 유형
- 암반사면 field investigation
- petrographic/weathering assessment
- slope stability evaluation

# 공간 구조
- bedded rock slope
- sandstone with interbedded siltstone and shale
- discontinuities / joints

# 적용 환경
- 진주성 촉석루
- 진주층
- 사암 기반암
- 미사암 및 셰일 호층

# 핵심 과정
- 물리풍화
- 화학풍화
- 수분침투
- 불연속면 누수
- 셰일 세편화
- 수목 근압에 따른 균열/절리
- 사면 불안정

# 식생 입력
- 실제 수목 뿌리의 근압 및 균열 관찰
- 정량 root biomass/state 없음

# 핵심 결과
현장에서:
- 크고 작은 수직/수평 절리
- 풍화/침식에 의한 여굴
- 불연속면을 통한 누수
- 셰일층 세편화
- **수목 근압에 의한 균열 및 절리**

가 관찰되었다.

암종 비교에서는:
- 셰일: 물리풍화 민감
- 미사암: 화학풍화 민감
- **사암: 물리·화학 양쪽에서 가장 높은 풍화 민감성**

으로 평가되었다.

# 고운사에 직접 사용할 수 있는 부분
한국 사암 사면에서:

```
water infiltration
+ discontinuity
+ tree root pressure
+ sandstone weathering
```

이 실제로 함께 나타날 수 있다는 지역적 field evidence.

따라서 고운사 sandstone fracture state와 root access를 완전히 분리된 현상으로 취급하지 않을 근거가 된다.

# 새로운 coupling이 필요한 부분
이 연구는 정량 annual weathering law를 제공하지 않는다.

따라서:
```
root biomass -> fracture rate
```
계수로 사용하면 안 된다.

# 한계
- 문화재 성곽지반
- 자연 산림사면이 아님
- anthropogenic exposure/geometry
- quantitative root force/rate 없음
- soil production model 아님

# 최종 판정
- **보조 채택: 한국 사암 + tree root + discontinuity + infiltration field evidence**
- numerical coefficient source 아님
- local plausibility evidence로 사용
