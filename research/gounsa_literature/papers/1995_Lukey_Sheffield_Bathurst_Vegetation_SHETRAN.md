# 서지정보
Lukey, B. T., Sheffield, J., Bathurst, J. C., Lavabre, J., Mathys, N., & Martin, C. (1995). Simulating the effect of vegetation cover on the sediment yield of Mediterranean catchments using SHETRAN. *Physics and Chemistry of the Earth, 20*, 427–432. https://doi.org/10.1016/0079-1946(95)00056-9
# 이 논문을 찾은 이유
고운사 수관 및 식생 피복의 침식/퇴적 연구와 연결되는 초기 SHETRAN 직접 적용.
# 연구 유형
동일 SHETRAN 계보의 토지피복/산불 전후 유사량 시나리오. 검토 수준: 학술 DB 서지 및 공개 초록.
# 공간 구조
프랑스 Rimbaud 산불 전후, Laval 침식 황무지 유역. 내부 격자 간 수송을 수행하지만 소규모 국지 퇴적 셀 실측 검증은 확인하지 않음.
# 적용 환경
지중해성 기후, 1990년 8월 산불로 식생이 제거된 Rimbaud, 골침식이 존재하는 Laval.
# 핵심 과정
수관/지표식생 보호와 강우 박리, 유수박리, 침식물 유사배출량 상한/하한 모의. 산불 전후 조건을 대조하고 Laval에 재조림 피복을 가정하여 반사실 실험을 수행.
# 식생 입력
산불 전후 식생피복 시나리오 및 산림 복원 조건; 실제 LAI 시간반응과 억새 포기 미시구조는 별도 확인 필요.
# 핵심 식
SHESED/SHETRAN의 직접강우/수관적하 충격과 유수박리, 격자별 수송 식 계보. 본문 식과 최신 원본 구현의 완전 일치를 주장하지 않음.
# 파라미터와 단위
토양 박리저항 불확실성을 바꿔 유사배출 범위를 구함. 정확한 보정계수 수치/단위는 공개 초록만으로 확인 불가.
# 원 논문의 구현 범위
동일 SHETRAN 계보의 토지피복/산불 전후 유사량 시나리오. 검토 수준: 학술 DB 서지 및 공개 초록.
# 고운사에 직접 사용할 수 있는 부분
초기 연구부터 식생피복의 전후 변화가 강우 유사배출에 미치는 영향을 기존 모델 안에서 검증했다는 직접 근거.
# 필요한 새로운 coupling
억새/참나무 수관자료, 개별 줄기/포기 유입 분배, 강우사상 내 지형 갱신은 고운사 목적에 맞는 별도 검증.
# 한계
Rimbaud와 Laval은 산불/황무지 유역이지 고운사와 동일하지 않고, 보고한 결과는 유역 유사배출량 중심.
