# 서지정보
Roering, J. J., Marshall, J., Booth, A. M., Mort, M., & Jin, Q. (2010). Evidence for biotic controls on topography and soil production. *Earth and Planetary Science Letters, 298*(1-2), 183-190. DOI: 10.1016/j.epsl.2010.07.040.

# 이 논문을 찾은 이유
Rossi et al. 2026이 forest-driven soil production의 핵심 선행근거로 인용한 Oregon Coast Range field evidence를 확인하기 위해 검토했다.

# 연구 유형
- field synthesis
- airborne lidar
- root inventories
- tree-disturbance surveys
- ground-penetrating radar

# 공간 구조
- steep forested hillslopes
- soil-bedrock interface
- tree-root interaction zone

# 적용 환경
- Oregon Coast Range
- steep forest
- sandstone-dominated regional context

# 핵심 과정
- root penetration into bedrock
- biological disturbance of soil/bedrock
- soil production
- pit-mound topography
- tree turnover
- forest stand age effects

# 식생 입력
- tree population / stand age
- root inventories
- root penetration
- no DGVM

# 핵심 결과
LiDAR shows pervasive forest-generated pit-mound roughness at small scales.

Root inventories, soil-production data, field observations and GPR indicate that tree roots interact vigorously with the soil-bedrock boundary and penetrate weathered/fractured bedrock.

The study argues that biological activity can exert first-order controls on:
```
bedrock-to-soil conversion
+
small-scale topographic modification
```

and that the mechanical ability of trees to interact with bedrock varies with stand age.

# 고운사에 직접 사용할 수 있는 부분
강한 field plausibility:
```
forest/root state
 -> soil-bedrock boundary disturbance
 -> soil production / surface roughness
```

Rossi 2026의 forest-structure / humped-production interpretation을 지지한다.

# 현재 scope 제한
중요:
이 논문의 tree turnover/tree throw 과정은 현재 고운사 production에서 제외되어 있다.

따라서 이 논문을 근거로:
```
tree throw
```
를 production에 되살리지 않는다.

사용 범위:
- biological control on soil production의 field evidence
- root penetration/bedrock interaction plausibility
- forest stand state가 soil-production mechanism에 영향을 줄 수 있다는 structural evidence

# 새로운 coupling이 필요한 부분
