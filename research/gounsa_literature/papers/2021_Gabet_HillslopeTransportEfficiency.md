# 이 논문을 찾은 이유
biomass가 hillslope transport efficiency에 미치는 효과의 부호와 물리기작을 최근 이론에서 확인하기 위해 검토했다.

# 연구 유형

- process synthesis

# 공간 구조
- hillslope transport framework

# 적용 환경
- 토사피복 사면

# 핵심 과정
- particle activation
- event frequency
- displacement
- bioturbation
- rainsplash

# 식생 입력
- biomass는 process intensity의 설명변수로 논의

# 핵심 식
현재 채팅에서 확정한 핵심은 transport efficiency D를 여러 사건과 이동거리 성분으로 분해하고, biomass 감소가 bioturbation은 약화시키지만 surface exposure로 rainsplash는 강화할 수 있다는 것이다.

# 원 논문의 구현 범위

# 고운사에 직접 사용할 수 있는 부분
total Kd 하나에 biomass를 단조함수로 넣지 말아야 한다는 근거.

# 새로운 coupling이 필요한 부분
LPJ-GUESS biomass를 physical shielding과 biogenic transport로 분리해 연결하는 것은 새로운 coupling.

# 한계
