# 서지정보
Chen, Y., Qi, Y., Wei, Y., Ning, W., & He, B. (2024). Root traits and soil detachment in response to variable slope gradients in a representative purple-soil sloping grassland. *CATENA, 239*, 107936.

# 이 논문을 찾은 이유
초본 root morphology와 rill erodibility의 최신 실험관계를 확인하기 위해 검토했다.

# 연구 유형
- 현장/실험

# 공간 구조
- sloping grassland plot

# 적용 환경
- purple-soil grassland

# 핵심 과정
- soil detachment
- rill erodibility
- critical shear

# 식생 입력
- root mass
- root morphology

# 핵심 식
rooted soil의 detachment capacity가 root-free soil보다 34.1-49.6% 낮고 rill erodibility 감소, critical shear 증가로 정리됨.

# 파라미터와 단위
root mass/morphology, slope gradient.

# 원 논문의 구현 범위
초본 root effect를 slope별로 비교.

# 고운사에 직접 사용할 수 있는 부분
초본 PFT root-trait parameterization 근거.

# 새로운 coupling이 필요한 부분
모델식으로 이식하면 새로운 coupling.

# 한계
단일 초본종 중심, 수치모델 아님.
