# 서지정보
김만일, 추창오. (2023). 산불 영향에 따른 토층의 광물학적 특성 변화에 관한 연구. *지질공학, 33*(1), 69–83. https://doi.org/10.9720/KSEG.2023.1.069

# 이 논문을 찾은 이유
국내 산불이 토양광물과 지표 및 하층토의 물성에 실제 변화를 일으키는지 확인하고, 산불 후 C/Cr 및 토양 안정성 변화의 국내 근거를 확보하기 위해 검토했다.

# 연구 유형
- 현장시료 분석
- XRD 분석
- 토양 물성분석

# 공간 구조
- 산불 발생지와 미발생지의 표토와 하층토 비교
- 수치모델 아님

# 적용 환경
- 2022년 울진 산불 관련 국내 산지
- 산불 발생지와 대조지

# 핵심 과정
- 산불 열영향
- 토양광물 조성 변화
- 점토광물 변화
- 토층 물성 변화
- 사면 안정성 변화 가능성

# 식생 입력
- 직접적인 biomass 입력 없음

# 핵심 식
수치 지형발달식은 제안하지 않는다. XRD와 토양물성 분석을 이용해 화재 전후에 해당하는 피해지와 대조지의 광물학적 차이를 비교한다.

# 파라미터와 단위
- mineral occurrence
- XRD
- topsoil/subsoil physical properties
정확한 세부 물성값은 원문 표 재검증 필요.

# 원 논문의 구현 범위
산불 발생지의 토양에서 뮬라이트, 아날사이트, 적철석 등이 소량 확인되고, 버미큘라이트와 혼합층상 광물 등 광물조성 차이가 나타남을 보고한다.

# 고운사에 직접 사용할 수 있는 부분
산불 열영향이 단순한 식생 소실을 넘어 토층의 광물학적, 물리적 특성까지 변화시킬 수 있다는 국내 근거.

# 새로운 coupling이 필요한 부분
이 광물변화를 erosion coefficient, weathering rate, C/Cr 생산률로 직접 변환하는 함수는 원 논문에 없으며 새로운 coupling이다.

# 한계
- fire spall 질량생산을 직접 정량화하지 않음
- 광물학적 변화와 토사유출량 사이의 직접 수치관계가 없음

# 최종 판정
- 국내 열영향과 토층변화의 보조근거
- 정량 fire-spall 또는 erosion 식의 직접 근거는 아님
