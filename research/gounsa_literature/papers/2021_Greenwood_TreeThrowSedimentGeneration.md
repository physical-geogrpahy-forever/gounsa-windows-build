# 서지정보
Greenwood, P., Bauer, J., & Kuhn, N. J. (2021). Assessing hillslope sediment generation potential by tree throw: A preliminary field study along a small river valley in the Jura Mountains, northwest Switzerland. Geographica Helvetica, 76, 319-333.

# 이 논문을 찾은 이유
tree throw가 실제로 얼마만큼의 토사를 이동시키는지 field-measured magnitude를 확보하기 위해 검토했다.

# 연구 유형
- 현장관측

# 공간 구조
- forested hillslope
- fresh tree-throw mounds

# 적용 환경
- 산림사면

# 핵심 과정
- tree throw
- sediment generation
- local surface hydrology

# 식생 입력
- uprooted trees
- tree-throw mound geometry

# 핵심 식
현재 채팅에서 보편 flux equation은 확인하지 않았다.

# 파라미터와 단위
displaced sediment volume, mound dimensions. 세부값 원문 재검증 필요.

# 원 논문의 구현 범위
fresh tree throws를 직접 측정해 displaced sediment volume과 현장조건을 평가한다.

# 고운사에 직접 사용할 수 있는 부분
Doane-type tree-throw flux에 필요한 event-scale soil-volume 제약의 현장근거.

# 새로운 coupling이 필요한 부분
LPJ-GUESS tree mortality를 event volume 및 frequency로 변환하는 것은 새로운 coupling이다.

# 한계
예비 현장연구이며 전체 LEM은 아니다.
