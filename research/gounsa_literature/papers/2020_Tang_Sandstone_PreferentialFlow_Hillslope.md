# 서지정보
Tang, Q., Duncan, J. M., Guo, L., Lin, H., Xiao, D., & Eissenstat, D. M. (2020). On the controls of preferential flow in soils of different hillslope position and lithological origin. *Hydrological Processes, 34*(22), 4295-4306. DOI: 10.1002/hyp.13883.

# 이 논문을 찾은 이유
고운사와 직접 관련성이 높은 **temperate forest sandstone catchment**에서 preferential flow가 ridge/midslope/toeslope에 따라 어떻게 달라지는지 확인하여, 식생-풍화 수문 interface의 sandstone-specific evidence를 확보하기 위해 검토했다.

# 연구 유형
- multi-year soil-moisture response analysis
- paired lithology comparison
- hillslope-position field hydrology

# 공간 구조
four positions:
- ridgetop
- north-facing midslope
- south-facing midslope
- toeslope

paired catchments:
- Shale Hills
- Garner Run sandstone

# 적용 환경
- central Pennsylvania
- neighbouring temperate-forest catchments
- shale-derived silt loam
- **sandstone-derived sandy loam**

# 핵심 과정
- preferential flow
- antecedent moisture
- hillslope position
- lithology
- vertical horizon-to-horizon flow path

# 식생 입력
both catchments are temperate forest.

Dynamic vegetation model 없음.

# 핵심 결과
Shale Hills had higher preferential-flow frequency than sandstone Garner Run at all four positions.

Largest contrast:
```
south-facing midslope
33.5% shale
vs
8.8% sandstone
```

Smallest:
```
ridgetop
18.7% shale
vs
13.2% sandstone
```

Drier antecedent conditions generally favored preferential-flow occurrence.

Characteristic flow pathways also differed by lithology.

Garner Run sandstone:
```
E/AE horizon -> Bw horizon
```

Shale:
```
Bw -> C horizon
```

# 고운사에 직접 사용할 수 있는 부분
이것은 매우 중요한 **forested sandstone hillslope hydrology** constraint다.

```
preferential flow
!= universal function of slope position
```

It depends jointly on:
- lithology
- soil horizons
- antecedent moisture
- hillslope position

Therefore Gounsa chemical-weathering hydrology should not infer deep flow solely from TWI/aspect.

Sandstone-specific profile/horizon structure matters.

# 새로운 coupling이 필요한 부분
A reduced Gounsa rule could use:
- antecedent saturation
- soil/profile horizon state
- slope position/convergence
- sandstone permeability/fracture proxy
to estimate shallow/deep flow partition.

This remains NEW COUPLING.
