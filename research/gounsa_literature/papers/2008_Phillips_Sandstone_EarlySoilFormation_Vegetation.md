# 서지정보
Phillips, J. D., Turkington, A. V., & Marion, D. A. (2008). Weathering and vegetation effects in early stages of soil formation. *Catena, 72*(1), 21-28. DOI: 10.1016/j.catena.2007.03.020.

# 이 논문을 찾은 이유
고운사의 약 100년 시간척도와 가까운 범위에서, 새로 노출된 resistant sandstone에 식생이 정착하면서 토양이 수십 년 내 형성되는 실제 사례가 있는지 확인하기 위해 검토했다.

# 연구 유형
- young chronosequence / exposed-bedrock field observation
- early pedogenesis study
- vegetation-weathering feedback interpretation

# 공간 구조
- newly exposed bedrock benches
- joints and fractures
- microtopographic depressions
- thin developing soil patches

# 적용 환경
- Ouachita Mountains, Arkansas
- resistant sandstone strata with weaker shale layers
- humid weathering-favorable climate
- rapidly colonizing vegetation

# 시간척도
노출 후:
```
<30 years
```

범위의 early soil formation.

이는 고운사 100년 postfire simulation과 비교적 가까운 단기 pedogenic precedent다.

# 핵심 과정
- fracture chemical weathering
- weak shale weathering
- mineral/organic debris accumulation
- local moisture accumulation
- vegetation colonization
- soil thickening
- tree establishment

# 식생 입력
- spontaneous/aggressive vegetation colonization
- subsequent tree establishment
- no dynamic vegetation model

# 핵심 관측
새로 노출된 bedrock surface에:
```
15-20 cm
```
정도의 soil cover가 3 decades 미만에 발달했다.

초기 apparent soil-thickness increase:
```
~5-10 mm yr^-1
```

그러나 이 값을 bedrock-to-soil production rate로 그대로 해석하면 안 된다.

왜냐하면 soil thickness 증가에는:
- in-situ weathering
- organic matter
- mineral debris accumulation
- fracture infill
- microtopographic trapping
이 함께 포함되기 때문이다.

# vegetation-soil feedback
초기:
```
fracture weathering
+ debris/moisture trapping
 -> pedogenic preparation
```

그 뒤:
```
vegetation colonization
 -> organic inputs / moisture retention / root activity
 -> faster local soil development
```

Tree ages suggest:
```
<10 years
```
의 pedogenic site preparation 후 tree establishment가 가능했을 수 있다.

# 고운사에 직접 사용할 수 있는 부분
매우 중요하다.

고운사 postfire 100년 model에서:
```
vegetation recovery
<-> thin-soil / fracture environment
```
feedback이 decadal timescale에서도 나타날 수 있다는 direct sandstone evidence다.

또 bare/near-bare sandstone에서 H 증가를:
```
P_sand
```
하나로만 설명하지 않고:
- in-situ weathering
- sediment/debris retention
- organic accumulation
을 분리해야 한다는 근거.

# Mode B/Mode C relevance
이 연구는:
```
bare bedrock
 -> initial fracture/weathering preparation
 -> vegetation establishment
 -> accelerated local soil development
```
sequence를 보여준다.

따라서:
- Mode B finite-depth hump
- Mode C vegetation-sensitive sensitivity
의 qualitative plausibility를 높인다.

하지만 정량식을 제공하지 않는다.

# 중요한 금지
다음처럼 사용하지 않는다.

```
P_sand = 5-10 mm yr^-1
```

해당 수치는 **soil-cover thickness accumulation**, not pure bedrock lowering or in-situ soil production.

또 spillway exposure/young surface는 wildfire-affected mature hillslope와 동일하지 않다.

# 한계
- anthropogenically exposed bedrock
- accumulation and in-situ production 분리 어려움
- humid Arkansas climate
- no process numerical model
- sandstone/shale interbedding
