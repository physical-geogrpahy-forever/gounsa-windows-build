# 서지정보
Ouyang, S., Li, L., Li, G., & Li, G. K. (2026). *A Novel Soil Chronometer: Uranium Comminution Ages Measure Soil Production Rates in a Deep Granitic Weathering Profile*. Geophysical Research Letters, 53, e2025GL119252. DOI: 10.1029/2025GL119252.

# 이 논문을 찾은 이유
고운사와 비교 가능한 동아시아 화강암 풍화단면에서 실제 soil-production rate의 크기를 확인하여 100년 simulation에서 full transient regolith model이 필요한지 판단하기 위해 검토했다.

# 연구 유형
- field geochronology
- 1D mass-transport inversion
- soil-production rate estimation

# 적용 환경
- subtropical southern China
- deep granitic weathering profile

# 핵심 결과
Uranium comminution age framework gives:

```
soil production rate
=
2.4 +/- 0.4 m Myr^-1
```

Equivalent:

```
0.0024 +/- 0.0004 mm yr^-1
```

100년 단순 환산:

```
약 0.24 +/- 0.04 mm per 100 yr
```

The result is reported as consistent with independent U-series and 10Be estimates at the site.

# 중요한 의미
This is a true soil-production estimate, not merely total surface erosion.

It shows that in some humid/subtropical granite weathering systems:

```
100-year soil production
<< 1 mm
```

can occur.

Therefore a century-scale model should first test whether regolith-front production is dynamically important before introducing a high-dimensional mineral-residence-time state system.

# 고운사에 직접 사용할 수 있는 부분
Use as lower-order regional magnitude constraint.

Together with Japanese weathered-granite surface-lowering studies, this suggests a plausible East Asian century-scale envelope ranging from sub-mm soil production to several-mm total lowering, depending on process definition and setting.

# 한계
- southern China, not Korea
- deep weathering profile
- one site
- long-term geochronological average
- does not provide vegetation-driven annual dynamics

# 최종 판정
**채택: century-scale soil-production magnitude constraint.**

Use to decide model complexity, not as a direct Gounsa production coefficient.
