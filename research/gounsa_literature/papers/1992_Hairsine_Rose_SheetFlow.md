# 서지정보
Hairsine, P. B., & Rose, C. W. (1992). Modeling water erosion due to overland flow using physical principles: 1. Sheet flow. *Water Resources Research, 28*(1), 237-243. https://doi.org/10.1029/91WR02380

# 이 논문을 찾은 이유
Iber+의 original-soil/loose-layer 구조와 shielding 개념의 물리적 원형을 확인하고, sheet/interrill erosion에서 자의적 armour factor 없이 deposited-layer protection을 계산하는 기존 모델을 검토하기 위해 찾았다.

# 연구 유형
- physically based erosion model
- multiclass sediment theory

# 공간 구조
- plane slope / sheet flow

# 적용 환경
- cohesive original soil plus deposited noncohesive layer

# 핵심 과정
- original-soil detachment
- deposited-layer redetachment
- deposition
- shielding
- entrainment-limited / transport-limited regimes
- multiclass sediment continuity

# 식생 입력
- 없음

# 핵심 구조
원토양에서 떨어진 sediment가 다시 표면에 퇴적해 noncohesive deposited layer를 만들고, 이 layer가 원토양을 부분 또는 완전히 shield한다.
H=1은 complete shielding/transport-limited state이고 H<1은 incomplete shielding/entrainment-limited state이다.

# 고운사에 직접 사용할 수 있는 부분
- armour/deposited-layer protection을 erosion state 자체가 변화시키는 self-organization으로 다루는 기존 이론
- Iber+ shielding formulation의 계보
- event-scale loose layer와 persistent profile을 구분할 근거

# 자의성 관련 판정
모델은 physical structure를 제공하지만 soil detachability와 entrainment resistance는 site-specific하다.
따라서 고운사에서는 해당 계수를 독립 측정 또는 실험으로 정해야 한다.

# 한계
석력 자체의 embeddedness와 weathering은 포함하지 않음.
