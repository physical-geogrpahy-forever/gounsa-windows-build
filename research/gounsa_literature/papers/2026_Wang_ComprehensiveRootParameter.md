# 서지정보
Wang, J., Liu, G., Yang, Y., & Wang, B. (2026). Construction of a Comprehensive Root Parameter to Reflect the Effect of Plant Root Systems on Soil Erosion. *Land Degradation & Development, 37*(10), 5345-5355.

# 이 논문을 찾은 이유
단일 root trait 대신 여러 root traits를 통합한 erosion parameterization의 최신 근거를 확인하기 위해 검토했다.

# 연구 유형
- 실험 + 지표구성

# 공간 구조
- plot

# 적용 환경
- 여러 천이단계 초본종

# 핵심 과정
- soil erosion resistance

# 식생 입력
- FineRootC와 대응 가능한 여러 root traits
- SRL
- root diameter
- root tissue density 등

# 핵심 식
여러 root traits를 통합한 comprehensive root parameter를 구성. 정확한 식은 원문 재검증 필요.

# 파라미터와 단위
복합 root-trait parameter. 세부 단위 원문 재검증 필요.

# 원 논문의 구현 범위
8개 초본종의 root system 차이를 종합지표로 표현.

# 고운사에 직접 사용할 수 있는 부분
PFT별 root biomass만으로 부족할 때 root-trait composite를 둘 근거.

# 새로운 coupling이 필요한 부분
LPJ-GUESS PFT별 고정/동적 root traits와 FineRootC를 종합지표로 결합하면 새로운 coupling.

# 한계
초본 중심이며 landscape model이 아님.

# 최종 판정
- 보조근거
