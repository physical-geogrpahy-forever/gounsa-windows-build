# 서지정보
Amundson, R., Heimsath, A., Owen, J., Yoo, K., & Dietrich, W. E. (2015). Hillslope soils and vegetation. *Geomorphology, 234*, 122-132. DOI: 10.1016/j.geomorph.2014.12.031.

# 이 논문을 찾은 이유
식생이 사면의 soil production, soil thickness, erosion, nutrient residence를 실제로 얼마나 지배하는지 종합한 핵심 review를 확인하기 위해 검토했다.

# 연구 유형
- review / synthesis
- vegetated vs effectively abiotic landscape comparison

# 공간 구조
- actively eroding hillslopes
- mobile soil mantle
- bedrock/regolith boundary

# 적용 환경
- global hillslope evidence
- soil-mantled landscapes

# 핵심 과정
- soil production
- weathering
- erosion
- soil thickness
- nutrient residence
- vegetation-soil feedback

# 식생 입력
dynamic numerical vegetation input은 없다.

정량적으로 논의하는 biological controls:
- plant productivity
- vegetation presence/absence
- soil mantle maintenance
- erosion resistance and biogenic disturbance

# 핵심 결과
여러 독립 접근의 synthesis에서 다음을 제시한다.

- plant-free world에서는 hillslope가 largely soil-free일 가능성
- plants may control maximum soil thickness on slopes
- vegetated landforms의 erosion rates가 comparable plant-free outcrops보다 약 1 order of magnitude 높을 수 있음
- vegetated hillslope soils는 N/P fertility를 유지할 만큼 긴 residence time 범위에 놓이는 경향

또한 soil production rates가 effective moisture와 plant productivity 증가에 따라 증가하는 broad pattern을 논의한다.

# 해석
중요한 점은 식생이 단순히 erosion을 억제하는 것만이 아니라:

```
vegetation
 -> weathering / soil production ↑
 -> soil mantle
 -> biogenic + hydrologic processes
 -> erosion / residence time
 -> nutrient availability
 -> vegetation
```

의 전체 feedback을 만든다는 것이다.

# 고운사에 직접 사용할 수 있는 부분
고운사에서 vegetation effect를 chemical weathering만으로 제한하면 부족하다는 강한 종합근거.

특히:
```
vegetation -> soil production
```
경로 자체를 optional sensitivity로 진지하게 검토할 근거다.

# 새로운 coupling이 필요한 부분
LPJ-GUESS biomass/root state를 quantitative P_sand modifier로 변환하는 universal equation은 이 review가 제공하지 않는다.
