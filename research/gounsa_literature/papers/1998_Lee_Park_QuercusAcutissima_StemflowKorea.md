# 서지정보
이헌호, 박재철. (1998). 소나무와 상수리나무림의 임내우 물수지 특성. 한국환경생태학회지, 12(3), 259–270. https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE09723888

# 이 논문을 검색한 이유
고운사 참나무 맹아의 수간유하우를 30%로 고정한 기존 EUROSEM 가상 시나리오가 일반 성숙 국내 참나무림의 관측과 얼마나 어긋나는지 검증.

# 연구 유형
[초록 직접 확인] 한국 성숙림 수관통과우/수간류 현장 관측(1995-09~1998-06); 수치침식 모형 아님.

# 공간구조
수관과 수간별 집수 측정. genuine 2D 산지 수문/침식 모의 불가.

# 적용환경
경북 소재 영남대학교 실험림/야산; 상수리나무 Quercus acutissima 및 소나무. 고운사 신갈/굴참 맹아와 수종 및 나이 차이.

# 핵심과정
상수리나무 GR에서 TF 76.9%, SF 3.8%; 소나무 TF 73.8%, SF 0.8%. I=100%-TF-SF로 보면 상수리 약 19.3%(관측기간 누적). 30개월 여러 사상 집계이므로 1h 10–50mm/h 사건의 성숙림 수치로도 직접 전환 불가.

# 식생입력
수종, 수관면적 CA, DBH, 임외우 GP와 상관 검토. 산불 직후 맹아의 줄기수, 수관구조, DBH 없음.

# 핵심식
P=TF+SF+I. 원 초록 상수리 SF 회귀식 S_f=0.03GP+12.25는 단위, 적용 강우범위, 절편에 대한 원문 검증 전 무비판 외삽하지 않는다.

# 파라미터와 단위
TF/SF/GR: 강우 수심 또는 백분율. 동일 측정 위치/기간 기준 비교.

# 고운사 활용
기존 30% oak SF 숫자는 참나무종 보편값이 아님을 보여주는 국내 관측. 맹아 기부의 집중은 별도 측정 필수.

# 필요한 새로운 coupling
줄기별 유하량 위치와 기부 침투/2D 침식.

# 한계
성숙림, 다른 참나무종, 기간 누적 관측; 맹아림 직접 적용 불가.

# 최종 판정
강우분배 기준 실측 보조근거, site parameter 미확정.
