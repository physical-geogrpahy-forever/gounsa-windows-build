# 서지정보
Burylo, M., Rey, F., Mathys, N., & Dutoit, T. (2012). Plant root traits affecting the resistance of soils to concentrated flow erosion. *Earth Surface Processes and Landforms, 37*(14), 1463-1470.

# 이 논문을 찾은 이유
교목과 초본을 동일 root coefficient로 처리하면 안 되는지 직접 비교하기 위해 검토했다.

# 연구 유형
- 현장/실험

# 공간 구조
- plot

# 적용 환경
- 산지 식생

# 핵심 과정
- concentrated-flow erosion

# 식생 입력
- root diameter
- fine-root fraction
- root surface area
- tensile strength

# 핵심 식
특정 단일 geomorphic model 식은 없음. root traits와 erosion resistance의 관계를 검증한다.

# 파라미터와 단위
종별 root traits.

# 원 논문의 구현 범위
Robinia, Pinus, herbaceous species 등 식물형별 차이를 비교.

# 고운사에 직접 사용할 수 있는 부분
PFT별 root coefficient 차등화의 실험근거.

# 새로운 coupling이 필요한 부분
root traits를 LPJ-GUESS PFT와 erosion coefficient에 연결하면 새로운 coupling.

# 한계
수치모델 아님.

- 보조근거
