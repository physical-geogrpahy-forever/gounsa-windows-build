# 서지정보
Pawlik, Ł., Phillips, J. D., & Šamonil, P. (2016). Roots, rock, and regolith: Biomechanical and biochemical weathering by trees and its impact on hillslopes—A critical literature review. *Earth-Science Reviews, 159*, 142-159. DOI: 10.1016/j.earscirev.2016.06.002.

# 이 논문을 찾은 이유
tree-root weathering을 physical soil-production term으로 넣을 때 어떤 기작이 실제로 지지되고 어떤 부분이 여전히 정량화되지 않았는지 확인하기 위해 검토했다.

# 연구 유형
- critical review

# 공간 구조
- tree to hillslope scale synthesis

# 적용 환경
- forest hillslopes
- rock / regolith / soil systems

# 핵심 과정
- root penetration of fractures
- biomechanical weathering
- biochemical weathering
- rhizosphere alteration
- soil production
- hillslope effects

# 식생 입력
- roots
- root architecture
- tree growth
- rhizosphere / mycorrhiza

# 핵심 식
보편적인 quantitative root-biomass-to-soil-production law를 제시하는 논문이 아니다.

# 파라미터와 단위
review synthesis. Process별 실험 및 관측자료를 비교한다.

# 원 논문의 구현 범위
tree roots가 weathering 및 hillslope development에 미치는 물리적, 화학적 효과를 비판적으로 정리한다.

# 고운사에 직접 사용할 수 있는 부분
root effects를 chemical과 biomechanical로 분리해야 한다는 구조적 근거.

# 새로운 coupling이 필요한 부분
LPJ-GUESS root biomass를 physical bedrock production rate로 직접 변환하는 식은 별도 검증이 필요하다.

# 한계
- numerical production model 아님
- universal coefficient 없음

# 최종 판정
- 보조근거
- 직접 biomass multiplier를 임의 생성하지 말아야 한다는 경계조건
