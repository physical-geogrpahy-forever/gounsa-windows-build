# 서지정보
Schwarz, M., Cohen, D., & Or, D. (2010). Root-soil mechanical interactions during pullout and failure of root bundles. *Journal of Geophysical Research: Earth Surface, 115*, F04035. https://doi.org/10.1029/2009JF001603

# 이 논문을 찾은 이유
LANDIS-II coarse/fine-root biomass를 shallow-landslide root reinforcement로 연결할 기존 mechanical model을 검토하기 위해 찾았다.

# 연구 유형
- mechanistic root-soil model
- Root Bundle Model
- strain-controlled pullout/failure

# 핵심 입력
- root diameter distribution
- root length-diameter relation
- root tortuosity
- branching
- tensile strength
- Young's modulus
- root-soil friction
- soil type
- confining pressure
- soil moisture

# 핵심 구조
서로 다른 직경의 root classes가 다른 displacement에서 pullout/breakage하며 progressive failure를 보인다.

Bundle force:
- diameter-class별 root force
- 각 class의 root number
를 합산한다.

Root-size distribution은 Weibull distribution으로 parameterize 가능하다.

# LANDIS-II와의 연결
NECN은:
- fine-root biomass
- coarse-root biomass
를 제공하지만 RBM이 요구하는:
- root diameter distribution
- root number
- root length
- tensile strength
를 직접 제공하지 않는다.

따라서 LANDIS-II root biomass만으로 RBM을 즉시 실행할 수 없다.

필요:
- species-specific root allometry
- root biomass -> diameter-class distribution
- species-specific mechanics

# 고운사 판정
shallow landslide에서 단순 apparent cohesion보다 물리적으로 강한 후보.
다만 root architecture dataset이 필수.

**shallow-landslide root mechanics의 핵심 기존 모델.**
