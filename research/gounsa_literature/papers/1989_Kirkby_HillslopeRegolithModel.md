# 서지정보
Kirkby, M. J. (1989). A model to estimate the impact of climatic change on hillslope and regolith form. *Catena, 16*(4-5), 321-341.

# 이 논문을 찾은 이유
vegetation biomass budget, regolith budget, landform evolution을 하나의 초기 수치모델에 넣은 직접 선례로 검토했다.

# 연구 유형
- 수치모델

# 공간 구조
- hillslope / regolith evolution

# 적용 환경
- 일반 사면

# 핵심 과정
- vegetation growth
- leaf fall
- organic soil accumulation
- solution/weathering
- creep
- splash
- wash
- shallow landslide

# 식생 입력
- vegetation biomass budget

# 핵심 식
이 채팅에서 원식 전체는 복구되지 않았으나 vegetation biomass, elevation/sediment, regolith을 함께 budget으로 둔다는 점은 확인됨.

# 파라미터와 단위
원문 재검증 필요.

# 원 논문의 구현 범위
생물량과 regolith/landform을 한 모델에서 동적으로 결합한다.

# 고운사에 직접 사용할 수 있는 부분
고운사 LPJ-GUESS + 지형발달 구조의 중요한 역사적 선례.

# 새로운 coupling이 필요한 부분
현대 LPJ-GUESS PFT/cohort와 과정별 biomass pool로 확장하면 새로운 coupling.

# 한계
세부 PFT 분리와 현대 유수침식/풍화식은 부족하다.

# 최종 판정

- 역사적 핵심
