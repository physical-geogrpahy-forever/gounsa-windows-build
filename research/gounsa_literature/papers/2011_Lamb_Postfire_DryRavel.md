# 서지정보
Lamb, M. P., Scheingross, J. S., Amidon, W. H., Swanson, E., & Limaye, A. (2011). A model for fire-induced sediment yield by dry ravel in steep landscapes. *Journal of Geophysical Research: Earth Surface, 116*, F03006. https://doi.org/10.1029/2010JF001878

# 이 논문을 찾은 이유
LANDIS-II의 산불 후 vegetation recovery를 steep-hillslope sediment storage/release에 연결할 기존 model을 찾기 위해 검토했다.

# 연구 유형
- process-based hillslope sediment continuity model
- postfire dry-ravel model
- field validation

# 적용환경
- San Gabriel Mountains, California
- steep slopes, including slopes steeper than angle of repose
- 2009 Station Fire

# 핵심 과정
- vegetation dams store loose sediment
- wildfire removes vegetation storage
- stored sediment is released as dry ravel
- vegetation recovery rebuilds storage
- soil production refills hillslope storage

# 핵심 상태
Maximum sediment storage is a function of:
- vegetation density
- sediment-storage capacity of plants
- contributing hillslope area

Recovery includes:
- vegetation regrowth rate
- soil production rate
- fire recurrence interval

# LANDIS-II와의 연결
LANDIS-II can provide:
- fire timing/severity
- cohort mortality
- vegetation recovery
- woody biomass / cohort state
- surface dead wood/litter

따라서 기존의 prescribed vegetation-recovery curve 대신 LANDIS-II recovery state를 driver로 사용할 가능성이 높다.

# 주의
LANDIS-II biomass가 Lamb의 vegetation density/storage capacity와 동일한 물리량은 아니다.
species/structure-specific sediment-storage relation이 필요하다.

# 최종 판정
**산불 후 dry ravel의 최우선 existing process model.**
