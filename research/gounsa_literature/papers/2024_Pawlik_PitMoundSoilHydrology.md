# 서지정보
Pawlik, Ł., Kasprzak, M., Ignatiuk, D., Głowacki, T., Milczarek, W., & Kajdas, J. (2024). Evaluation of the hillslope fine-scale morphology under forest cover with pit-mound topography - Integration of geomorphometry, geophysical methods, and soil features. Geomorphology, 109283. https://doi.org/10.1016/j.geomorph.2024.109283

# 이 논문을 찾은 이유
tree throw를 한 번의 sediment-flux event로 끝내도 되는지, pit와 mound가 이후 수십 년간 토양과 수문에 다른 상태를 남기는지 확인하기 위해 검토했다.

# 연구 유형
- 현장관측
- geomorphometry + geophysics + soil analysis

# 공간 구조
- pit-mound microtopography

# 적용 환경
- forested hillslope

# 핵심 과정
- tree throw legacy
- microtopographic hydrology
- soil differentiation

# 식생 입력
- 과거 uprooting 흔적

# 핵심 식
보편 geomorphic flux equation은 현재 채팅에서 확인하지 않았다.

# 파라미터와 단위
moisture, organic matter, Corg, silt, electrical resistivity. 세부 단위 원문 재검증 필요.

# 원 논문의 구현 범위
pit와 mound 사이의 수분, 토양, 지화학적 차이를 공간적으로 확인한다.

# 고운사에 직접 사용할 수 있는 부분
100년 모의에서 tree-throw event 후 microtopographic legacy를 즉시 평탄화하지 않아야 할 가능성을 보여준다.

# 새로운 coupling이 필요한 부분
pit/mound 상태를 LPJ-GUESS soil moisture와 feedback시키는 것은 새로운 coupling이다.
