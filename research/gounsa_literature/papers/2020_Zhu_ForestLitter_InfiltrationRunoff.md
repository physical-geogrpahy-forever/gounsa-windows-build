# 서지정보
Zhu, H., Wang, G., Aa, Y., & Liu, T. (2020). Ecohydrological effects of litter cover on the hillslope-scale infiltration-runoff patterns for layered soil in forest ecosystem. *Ecological Engineering, 155*, 105930. https://doi.org/10.1016/j.ecoleng.2020.105930

# 검토 이유
forest litter를 hillslope infiltration-runoff model에 직접 넣는 기존 hydrological model을 검토.

# 핵심 과정
- vegetation interception
- litter interception
- modified Green-Ampt infiltration
- hillslope runoff

# 장점
LANDIS-II NECN surface litter state를 hydrological storage/interception에 연결하는 existing model precedent.

# 중요한 한계
storm period infiltration을 과소추정했고, 저자들은 soil fragments가 earth-rock interface preferential flow path를 만들 수 있으나 모델이 이를 무시한다고 지적.

# 고운사 의미
매립 석력이 많은 고운사에는 이 modified Green-Ampt를 그대로 사용할 수 없음.

# 판정
forest litter-hydrology reference.
stony-soil production hydrology에는 단독 사용 불가.
