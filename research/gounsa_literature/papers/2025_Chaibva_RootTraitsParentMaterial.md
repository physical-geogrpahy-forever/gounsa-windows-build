# 서지정보
Chaibva, P., McCloskey, C. S., Sizmur, T., Greenfield, L. M., Ahmed, S., et al. (2025). Uncovering plant root traits and mechanisms that enable penetration, exploration, and exploitation of soil parent materials: A systematic review. *Plant and Soil, 517*, 1187-1209.

# 이 논문을 찾은 이유
C/Cr와 bedrock까지 침투하는 root traits를 체계적으로 정리한 최신 근거를 찾기 위해 검토했다.

# 연구 유형
- 체계적 리뷰

# 공간 구조
- soil parent material / C horizon / saprolite / bedrock

# 적용 환경
- Critical Zone

# 핵심 과정
- root penetration
- biomechanical weathering
- exudation
- mycorrhizal interaction

# 식생 입력
- radial pressure
- root biomass investment
- fine-root development
- root hairs
- exudates
- mycorrhiza
- growth angle
- root-tip geometry

# 핵심 식
단일 지형모델식은 없음. root mass 하나만으로 parent-material penetration을 설명할 수 없다는 종합결론이 핵심.

# 파라미터와 단위
trait-specific. 원문 표 재검증 필요.

# 원 논문의 구현 범위
parent material 침투와 이용에 필요한 root traits/mechanisms를 체계적으로 정리.

# 고운사에 직접 사용할 수 있는 부분
C/Cr root access를 FineRootC 하나가 아니라 PFT별 rooting depth와 mechanical/chemical traits로 제약할 근거.

# 새로운 coupling이 필요한 부분
LPJ-GUESS root traits를 physical/chemical weathering rate에 연결하면 새로운 coupling.

# 한계
리뷰이며 실행형 geomorphic model은 아님.

- 보조근거
