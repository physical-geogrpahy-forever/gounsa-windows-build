# 서지정보
Kirwan, M. L., & Shugart, H. H. (2008). Forest succession-tree throw 결합 연구. 이 채팅에서는 정확한 논문 제목과 DOI가 완전히 복구되지 않았다.

# 이 논문을 찾은 이유
개체 기반 산림천이와 tree-throw sediment transport의 초기 결합 선례로 검토했다.

# 연구 유형
- 수치모델

# 공간 구조
- forest succession + hillslope disturbance

# 적용 환경
- 산림

# 핵심 과정
- tree throw

# 식생 입력
- 개체별 직경
- 성장
- 사망
- canopy competition

# 핵심 식
토양 이동량과 이동거리를 개별 나무 크기와 연결하는 구조로 정리됨. 정확한 원식은 원문 재검증 필요.

# 파라미터와 단위
DBH, density, mortality/throw probability. 세부값 미복구.

# 원 논문의 구현 범위
FORET 계열 산림천이와 tree throw를 결합한 초기 선례로 이 채팅에서 취급했다.

# 고운사에 직접 사용할 수 있는 부분
WoodC를 직접 지형계수로 바꾸기보다 cohort structure를 tree throw로 변환하는 근거.

# 새로운 coupling이 필요한 부분
LPJ-GUESS cohort 출력 연결은 새로운 coupling.

# 한계
