# 서지정보
De Baets, S., Poesen, J., Knapen, A., & Galindo, P. (2007). Impact of root architecture on the erosion-reducing potential of roots during concentrated flow. *Earth Surface Processes and Landforms, 32*(9), 1323-1345.

# 이 논문을 찾은 이유
같은 root mass라도 architecture가 침식억제효과를 바꾸는지 확인하기 위해 검토했다.

# 연구 유형
- 현장/실험

# 공간 구조
- plot / flume

# 적용 환경
- 식생토양

# 핵심 과정
- concentrated-flow erosion

# 식생 입력
- root architecture
- fine/coarse root structure

# 핵심 식
단일 보편식보다 root architecture에 따라 detachment response가 달라지는 실험결과.

# 파라미터와 단위
root architecture metrics. 세부값 원문 재확인 필요.

# 원 논문의 구현 범위
root morphology가 erosion reduction을 조절함을 정량화.

# 고운사에 직접 사용할 수 있는 부분
PFT별 root trait table이 필요하다는 근거.

# 새로운 coupling이 필요한 부분
LPJ-GUESS FineRootC와 architecture trait을 결합하는 것은 새로운 coupling.

# 한계
모델논문 아님.
