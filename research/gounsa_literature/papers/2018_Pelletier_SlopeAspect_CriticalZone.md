# 이 논문을 찾은 이유
기존 아카이브에서 biomass-dependent hillslope diffusivity의 직접 numerical model로 기록되어 있어 원문 역할을 재검증했다.

# 연구 유형
- Critical Zone synthesis / conceptual framework
- field observations + cross-process interpretation
- 단일 biomass-diffusivity numerical model 아님

# 공간 구조
- slope-aspect contrasts
- mountain Critical Zone comparison

# 적용 환경
- aspect-driven differences in water, vegetation, weathering and topography

# 핵심 과정
- ecohydrology
- vegetation
- regolith/soil development
- weathering
- hillslope asymmetry
- erosion feedbacks

# 식생 입력
Vegetation biomass/productivity and ecosystem structure are discussed as components of aspect-dependent Critical Zone feedbacks.

# 핵심 판정
The DOI 10.1002/esp.4306 does **not** correspond to a paper whose main model is a direct:
```
biomass -> K_d
```
hillslope-diffusivity equation.

Earlier archive wording overstated this source.

# 고운사에 직접 사용할 수 있는 부분
- vegetation, hydrology, weathering and topography can covary and feedback
- long-term aspect/vegetation/topography interpretation
- conceptual consistency check only

# 새로운 coupling이 필요한 부분
Using LPJ-GUESS biomass to change background diffusivity based on this paper would be unsupported.
