# 서지정보
Anderson, S. P., Kelly, P. J., Hoffman, N., Barnhart, K., Befus, K., & Ouimet, W. (2021). Is This Steady State? Weathering and Critical Zone Architecture in Gordon Gulch, Colorado Front Range. In *Hydrogeology, Chemical Weathering, and Soil Formation*, Geophysical Monograph Series 257, pp. 231-252. DOI: 10.1002/9781119563952.ch13.

# 이 논문을 찾은 이유
2011 Gordon Gulch 결과를 장기 관측과 geophysics까지 포함해 재평가했을 때, aspect/vegetation contrast가 chemical weathering, mechanical weathering, soil thickness, erosion에 각각 어떻게 나타나는지 확인하기 위해 검토했다.

# 연구 유형
- long-term synthesis
- geophysics + geomorphology + geochemistry
- aspect natural experiment

# 공간 구조
- north- and south-facing hillslopes
- mobile regolith
- weathered bedrock
- deep Critical Zone

# 적용 환경
- Gordon Gulch, Colorado Front Range
- unglaciated, periglacially influenced semiarid montane catchment
- contrasting forest/microclimate by aspect

# 핵심 과정
- bedrock weathering
- mechanical weakening
- chemical alteration
- mobile-regolith production
- hillslope transport
- long-term erosion
- aspect climate/vegetation contrast

# 식생 입력
dynamic vegetation model 없음.

Vegetation은 aspect-dependent environmental state의 일부로 해석된다.

# 핵심 결과

## deep weathering
weathered bedrock은 평균 약 12 m 깊이까지 발달한다.

denudation rate 약:
```
3.1 cm kyr^-1
```
기준으로 >350 kyr의 weathering exposure를 의미한다.

## aspect
north-facing weathered rock:
- 더 깊음
- 더 mechanically weak

south-facing보다 차이가 뚜렷하다.

하지만 mobile regolith:
```
~0.4 m
```
정도로 얇고 aspect 간 비교적 균일했다.

## chemistry
heterogeneous biotite gneiss와 낮은 chemical-weathering signal 때문에 aspect별 chemical alteration 차이는 정량화하기 어려웠다.

## erosion / transport
cosmogenic erosion rate와 mobile-regolith residence time에서는 aspect-controlled long-term difference가 뚜렷하지 않았다.

## interpretation
이 site에서는:
```
mechanical bedrock weathering
```
이 bedrock weakening과 mobile-regolith production에 중요한 역할을 하는 것으로 해석된다.

# 고운사에 직접 사용할 수 있는 부분
아주 중요한 경계조건:

```
aspect / vegetation contrast
 -> deeper weathering
```
관측이 있어도,

```
aspect / vegetation contrast
 -> higher chemical weathering
 -> thicker mobile soil
 -> higher erosion
```
를 자동으로 추론하면 안 된다.

따라서 고운사는 최소 세 상태를 분리한다.

```
weathering-front depth
weathered-rock mechanical state
mobile-soil thickness H
```

# 새로운 coupling이 필요한 부분
식생 회복과 deep bedrock mechanical/chemical weathering을 연결하려면 별도 process model이 필요하다.

# 한계
- biotite gneiss
- long-term system
- postfire 100-year model이 아님
- vegetation causality를 독립적으로 분리하지 않음

# 최종 판정
- **채택: aspect/vegetation-weathering 해석의 핵심 caution**
- deep weathering과 mobile soil production을 분리
- chemical effect를 과대해석하지 않도록 제약
