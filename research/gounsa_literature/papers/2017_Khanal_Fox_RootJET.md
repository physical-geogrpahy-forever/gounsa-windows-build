# 서지정보
Khanal, A., & Fox, G. A. (2017). Detachment characteristics of root-permeated soils from laboratory jet erosion tests. *Ecological Engineering, 100*, 335-343. https://doi.org/10.1016/j.ecoleng.2016.10.081

# 이 논문을 찾은 이유
JET를 이용해 root-permeated soil의 K_d와 tau_c를 직접 측정할 수 있는지, 그리고 root traits가 어느 parameter에 일관되게 반영되는지 확인하기 위해 검토했다.

# 연구 유형
- laboratory mini-JET
- root-permeated vs bare soils

# 공간 구조
- soil core scale

# 적용 환경
- rooted soil samples
- root diameter 0.5-1.7 mm

# 핵심 과정
- erosion resistance
- critical shear stress
- erodibility coefficient
- root traits

# 식생 입력
- root diameter
- root-permeated treatment

# 핵심 결과
- root-permeated samples가 high shear에서 더 erosion-resistant
- k_d는 root diameter와 유의한 음의 관계
- tau_c와 root parameters 사이에는 일관된 유의관계가 없었음
- root effect는 주로 erodibility coefficient에서 명확

# 고운사에 직접 사용할 수 있는 부분
- 뿌리를 포함한 intact core에서 Iber+ K_d/tau_s를 직접 독립 측정할 수 있다는 근거
- root effect를 K_d 중심으로 두는 추가 근거
- tau_s는 root biomass regression으로 강제하지 않을 근거

# 새로운 coupling이 필요한 부분
LPJ root pools에서 현장 root diameter/RLD/RMD state로 변환하는 단계.
