# 서지정보
Cho, J., & Mostaghimi, S. (2009). *Dynamic agricultural non-point source assessment tool (DANSAT): Model application*. Biosystems Engineering, 102(4), 500-515. DOI: 10.1016/j.biosystemseng.2009.01.012.

# 이 논문을 찾은 이유
DANSAT의 dynamic plant/erosion routines가 실제 watershed application에서 어떻게 사용되는지 확인하기 위해 검토했다.

# 연구 유형
- distributed numerical-model application

# 공간 구조
- distributed grid-based watershed model
- genuine 2D SWE는 아님

# 적용 환경
- two agricultural watersheds in Virginia, USA

# 핵심 과정
- hydrology
- sediment yield
- temporal/spatial BMP response
- interrill/rill/channel detachment via DANSAT development model

# 식생 입력
dynamic soil, plant growth and residue components inherited from the development paper.

# 핵심 식
Development paper와 동일 model core. Application paper는 temporal/spatial evaluation, sensitivity, watershed application에 초점.

# 파라미터와 단위
원문 table 기준.

# 원 논문의 구현 범위
spatially and temporally changing agricultural management impacts on hydrology and sediment.

# 고운사에 직접 사용할 수 있는 부분
DANSAT dynamic vegetation/erosion architecture가 실제 distributed watershed simulation에 적용된 선례.

# 새로운 coupling이 필요한 부분
mountain forest LPJ-GUESS integration은 **새로운 coupling**.

# 한계
- agricultural watersheds
- genuine 2D 아님

# 최종 판정
**보조근거.**
