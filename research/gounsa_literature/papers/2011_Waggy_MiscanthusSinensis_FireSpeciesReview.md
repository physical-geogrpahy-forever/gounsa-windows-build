# 서지정보
Waggy, M. A. (2011). Miscanthus sinensis, Chinese silvergrass. Fire Effects Information System species review. USDA Forest Service. https://doi.org/10.2737/feis-species-review-missin

# 검색 이유
고운사 산불 직후 억새가 종자보다 지하경 기반 빠른 재생을 할 수 있는지, 계절/번성기/포기생육 조건 검토.

# 연구 유형
[USDA FEIS 원문 직접 확인, 인용 근거는 review 등급] 문헌 종합, 직접 유수침식 수치모형 아님.

# 공간구조
bunchgrass/tussock graminoid, rhizomatous herb. patch/clonal spatial pattern 논의.

# 적용환경
M. sinensis 아시아 원산, 일본/한국, 화재 관리된 일본 초지 등. 고운사 실측 아님.

# 핵심과정
지상 잎 및 줄기는 fire top-kill, 지하경은 종종 생존, rhizome resprouting and tillering 중심. 일본 red pine prescribed burn example: rhizome sprout 0.62/m² vs seedling 0.02/m². 억새 초지는 전정, 방목, burning으로 maintained subclimax 예시. 산불 직후 canopy 거의 0이어도 rhizome alive 가능하므로 canopy and root initial states decoupled.

# 식생입력
rhizome reserve, tiller density, plant height, live-dead standing matter, season, postfire age.

# 핵심식
직접 토양박리 물리식 없음.

# 파라미터와 단위
sprouts/m², seedling/m². 0.62/0.02는 일본 특수 plot 관측이며 고운사 초기 지하경 개수 아님.

# 고운사 활용
억새 canopy cover와 root biomass 같은 값으로 보정 금지. 계절별 초기조건과 fire resprout 차이.

# 새로운 coupling
Rhizome tiller dynamics + canopy events + roots/soil + 2D event model.

# 한계
리뷰, 여러 서식지, 고운사 지질/산불강도 다름.

# 최종 판정
종 생태 리뷰 채택.
