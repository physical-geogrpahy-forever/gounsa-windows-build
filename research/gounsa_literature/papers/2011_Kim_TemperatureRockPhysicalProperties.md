# 서지정보
김재환, 이명성, 이미혜, 이재만, 박성미. (2011). 암석의 물리적 특성 변화에 대한 온도의 영향. *암석학회지, 20*(3), 141–148. DOI는 원문 재검증 필요.

# 이 논문을 찾은 이유
고온 가열이 화강암과 사암의 공극률, 흡수율, 초음파속도 등 암석 물성에 미치는 영향을 확인하기 위해 검토했다.

# 연구 유형
- 실내 가열실험

# 공간 구조
- 암석시료 수준

# 적용 환경
- 화강암류, 대리암, 사암
- 400°C와 600°C 가열

# 핵심 과정
- 열손상
- 공극률 변화
- 흡수율 변화
- 초음파속도 변화

# 식생 입력
- 없음

# 핵심 식
수치 지형발달식은 제안하지 않는다.

# 파라미터와 단위
- temperature: °C
- porosity
- absorption
- ultrasonic velocity

# 원 논문의 구현 범위
가열 전후 암석 물성 변화를 실험적으로 비교한다.

# 고운사에 직접 사용할 수 있는 부분
고온에 따른 암석 물성 약화의 국내 기작 근거.

# 새로운 coupling이 필요한 부분
가열실험 결과에서 fire spall 생산량 또는 장기 풍화율을 계산하는 연결은 새로운 coupling이다.
