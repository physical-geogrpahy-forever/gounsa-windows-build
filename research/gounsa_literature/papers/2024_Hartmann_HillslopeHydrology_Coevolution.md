# 서지정보
Hartmann, A., & Blume, T. (2024). The Evolution of Hillslope Hydrology: Links Between Form, Function and the Underlying Control of Geology. *Water Resources Research, 60*(3), e2023WR035937. DOI: 10.1029/2023WR035937.

# 이 논문을 찾은 이유
soil formation, vegetation succession, preferential flow, lateral flow가 수백~수천년 동안 어떻게 함께 공진화하는지 확인하여 고운사 100년 postfire transition의 방향성을 검토하기 위해 읽었다.

# 연구 유형
- hillslope chronosequence synthesis
- hydrologic response experiments
- soil/vegetation/hydrology coevolution analysis

# 공간 구조
- two glacial hillslope chronosequences
- ages from decades to >10 kyr
- siliceous vs calcareous parent material

# 적용 환경
- Swiss Alps glacier forefields

# 핵심 과정
- soil formation
- vegetation succession
- soil acidification
- preferential flow
- lateral subsurface flow
- water storage
- geology-dependent hydrologic evolution

# 식생 입력
- pioneer plants
- grassland
- herbaceous/shrub vegetation
- aboveground biomass
- root-system architecture

# 핵심 결과
Siliceous parent material:
```
soil acidification
 -> organic matter accumulation
 -> greater storage
 -> transition toward lateral subsurface flow
```

Vegetation development and root architecture were associated with changes in preferential-flow fraction and flow type.

In older siliceous stages:
- more structured soils
- organic accumulation
- heterogeneous infiltration
- more lateral flow

Calcareous parent material retained faster vertical flow for much longer because buffering limited comparable pedogenic evolution.

# 고운사에 직접 사용할 수 있는 부분
중요한 구조적 근거:

```
weathering / pedogenesis
 -> soil structure
 -> hydrology
 -> vegetation

vegetation
 -> roots / organic layers
 -> hydrology
 -> pedogenesis
```

즉 hydrology itself coevolves with vegetation and soil formation.

고운사 100년 모델에서도 hydrologic parameters를 완전 고정값으로 두는 것의 한계를 보여준다.

# 새로운 coupling이 필요한 부분
