# 서지정보
Welivitiya, W. D. D. P., & Hancock, G. R. (2024). Quantifying mine waste rock physical weathering rate and processes for improved geomorphic post-mining landforms. *Geomorphology, 463*, 109357. https://doi.org/10.1016/j.geomorph.2024.109357

# 이 논문을 찾은 이유
SSSPAM의 weathering transition을 arbitrary rate로 두지 않고 실제 실험에서 particle-size-dependent weathering rate와 daughter-size geometry를 결정하는 방법이 있는지 확인하기 위해 검토했다.

# 연구 유형
- laboratory physical-weathering experiment
- mathematical parameter-estimation method
- SSSPAM weathering parameterisation

# 공간 구조
- particle/material scale
- repeated wet-dry cycles

# 적용 환경
- four mine waste-rock materials
- Bowen Basin, Australia

# 핵심 과정
- wetting/drying weathering
- heating/cooling test
- particle-size-dependent weathering
- daughter-size distribution
- armour breakdown potential

# 식생 입력
- 없음

# 핵심 결과
- 32 wet-dry cycles에서 모든 material의 PSD가 finer 방향으로 이동
- heating/cooling은 이 실험에서 유의한 weathering effect가 없었음
- 큰 particles가 작은 particles보다 높은 weathering rate를 보이는 사례가 많음
- SSSPAM용 weathering mechanism/rate parameters를 실험자료에서 산출하는 수학적 방법을 제시

# 고운사에 직접 사용할 수 있는 부분
- weathering transition rate를 임의 선정하지 않고 **고운사 사암의 wet-dry / thermal-spall 실험에서 직접 추정하는 방법론**
- size-dependent transition matrix calibration의 existing published method

# 한계
- lithology가 고운사 사암과 다름
- 고운사에는 thermal fire-spall 직후 과정과 postfire weathering을 구분해야 함

# 최종 판정
- weathering parameter estimation methodology 채택
- 수치 parameter 자체는 고운사에 직접 이식 금지
