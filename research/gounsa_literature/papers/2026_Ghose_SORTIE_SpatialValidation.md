# 서지정보
Ghose, A., Marchand, P., Maleki, K., & Girona, M. M. (2026). Evaluating an individual-based model's ability to reproduce fine-scale spatial structure in boreal mixed forests. Ecological Modelling, 519, 111620. DOI: 10.1016/j.ecolmodel.2026.111620

# 이 논문을 찾은 이유
SORTIE-ND의 fine-scale 개체목 공간패턴이 산불 후 천이자료에서 실제 검증되는지 최신 근거를 확인하기 위해 검토했다.

# 연구 유형
- model validation
- fine-scale spatial point-pattern evaluation

# 공간 구조
- spatially explicit individual trees
- within- and between-species neighbourhood pattern
- postfire chronosequence

# 적용 환경
- Québec boreal mixedwoods
- younger postfire stands에서 249-year chronosequence 비교

# 핵심 과정
- recruitment
- growth
- mortality
- neighbourhood interactions

# 식생 입력
- species
- life stage
- individual tree locations

# 핵심 결과
SORTIE-ND는 balsam fir와 trembling aspen의 fine-scale pattern은 비교적 잘 재현했으나 birch clustering은 과소평가했다. 저자들은 vegetative propagation과 microsite processes의 누락을 제한점으로 지적했다.

# 고운사에 직접 사용할 수 있는 부분
- LiDAR point-pattern validation 방법
- postfire fine-scale forest spatial dynamics benchmark
- 개별목 위치 기반 모델 검증 설계

# 새로운 coupling이 필요한 부분
- root distribution
- litter/root turnover
- geomorphic microsite and soil-depth feedback
- Korean species parameterization

# 한계
fine-scale spatial tree dynamics 검증 연구이지 root/soil process model은 아니다.

# 최종 판정
- 보조근거
- SORTIE-ND 공간구조 검증에는 강함
- 주 vegetation-geomorph engine으로는 root/soil feedback 부족
