# 서지정보
Billings, S. A., et al. (2025). Contrasting Depth Dependencies of Plant Root Presence and Mass Across Biomes Underscore Prolific Root-Regolith Interactions. AGU Advances. https://doi.org/10.1029/2025AV002072

# 이 논문을 찾은 이유
고운사에서 root-access depth가 AB soil depth보다 깊고 C/Cr까지 뿌리가 존재할 수 있다는 구조를 최신 자료로 검증하기 위해 검토했다.

# 연구 유형
- 종합 관측 / 데이터 synthesis

# 공간 구조
- vertical regolith profiles
- biome comparison

# 적용 환경
- 여러 biome
- B/C horizon 및 weathered regolith

# 핵심 과정
- root-regolith interaction
- deep rooting
- potential weathering and physical disturbance

# 식생 입력
- root presence
- root mass with depth
- biome

# 핵심 식
이 채팅에서 직접 복구된 보편 geomorphic equation은 없다.

# 파라미터와 단위
root presence, root mass, depth. 세부 단위와 profile statistics는 원문 재검증 필요.

# 원 논문의 구현 범위
깊은 regolith에서의 root presence와 mass가 biome별로 광범위함을 제시한다.

# 고운사에 직접 사용할 수 있는 부분
Z_r > H_AB를 허용하고 C/Cr root access를 독립 상태로 유지해야 한다는 최신 근거.

# 새로운 coupling이 필요한 부분
deep root mass를 chemical/mechanical weathering rate로 바꾸는 것은 새로운 coupling이다.

# 한계
수치 풍화모델이 아니다.
