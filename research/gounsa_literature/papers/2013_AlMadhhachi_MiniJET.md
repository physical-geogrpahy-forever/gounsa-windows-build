# 서지정보
Al-Madhhachi, A. T., Hanson, G. J., Fox, G. A., Tyagi, A. K., & Bulut, R. (2013). Measuring soil erodibility using a laboratory mini jet. *Transactions of the ASABE, 56*(3), 901-910. https://doi.org/10.13031/trans.56.9742

# 이 논문을 찾은 이유
고운사에서 많은 지점과 식생상태를 반복 측정하기 위해 JET의 소형화된 방법으로 K_d와 tau_s를 독립 측정할 수 있는지 확인하기 위해 검토했다.

# 연구 유형
- laboratory method validation
- mini-JET vs original JET

# 공간 구조
- soil core scale

# 적용 환경
- silty sand
- clayey sand
- controlled soil moisture and density

# 핵심 과정
- critical shear stress
- erodibility coefficient
- excess shear erosion

# 식생 입력
- 없음

# 핵심 결과
mini-JET와 original JET는 k_d에 대해 통계적으로 유사한 결과를 보였다.
tau_c는 장치 규모와 equilibrium-depth determination에 더 민감했다.

# 핵심 식
```
epsilon_r = k_d (tau - tau_c)
```

# 고운사에 직접 사용할 수 있는 부분
- 많은 undisturbed samples에 대한 반복 K_d 측정
- root-state / postfire-age별 independent erosion resistance dataset 구축

# 주의
tau_c는 mini-JET에서 장치/해석법 sensitivity가 더 크므로, 고운사 production parameter는 가능하면 original JET 또는 flume과 교차검증한다.

# 최종 판정
- K_d 반복측정에 유용
- tau_s 단독기준으로는 original JET/flume cross-check 권장
