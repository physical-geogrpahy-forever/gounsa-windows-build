# Gounsa Literature Archive

고운사 산불 후 식생-지형 상호작용 모델 문헌검토를 장기적으로 축적하는 고정 저장소이다.

## 디렉터리 구조

- `papers/`: 논문 1편당 Markdown 1개
- `models/`: 여러 논문에 걸친 모델 계보 정리
- `decisions/`: 채택/보류/탈락 결정 기록
- `sessions/`: 채팅별 인계서 및 복구본
- `MASTER.md`: 전체 문헌검토 통합본
- `SYSTEM.md`: 모든 채팅이 따라야 할 기록 규칙
- `INDEX.md`: 논문/모델/결정 파일 목록

## 핵심 원칙

1. 논문 1편당 파일 1개를 만든다.
2. 새 논문을 검토하면 먼저 해당 논문 파일을 저장한다.
3. 중요한 결론 변화가 생기면 `decisions/`에 별도 기록한다.
4. 전체 요약은 `MASTER.md`에 누적한다.
5. 채팅 종료 전 반드시 `sessions/`에 인계서를 남긴다.
6. COPLAS는 고운사 최종모델 근거에서 제외한다.
7. MUSLE는 고운사 산지 유수침식 최종식에서 제외한다.
8. 기존 문헌에 없는 결합은 반드시 `새로운 coupling`이라고 명시한다.
9. 현장실험 상관식과 실제 수치모델 구현을 구분한다.
10. 이미 검증된 결론을 반복 검색하지 않고 INDEX와 MASTER를 먼저 확인한다.
