# RHESSys + WMFire

업데이트: 2026-09-23

## 왜 검토했는가
고운사 요구와 매우 비슷한 distributed mountain watershed + fire + overstory/understory + daily ecohydrology 구조를 이미 갖고 있어, demographic cohort engine으로도 사용할 수 있는지 확인했다.

## 강점
RHESSys:
- GIS-based spatial hierarchy: basin -> hillslope -> zone -> patch -> canopy stratum
- patch is spatially explicit
- arbitrary patch size; many studies use about 30–120 m
- explicit hillslope flow routing and downslope water redistribution
- daily carbon, water, nitrogen processes
- multiple vertical canopy strata
- overstory and understory can coexist
- stratum-level photosynthesis, transpiration and radiation attenuation
- litter and soil pools
- daily mortality parameters
- root-depth and vegetation-specific physiology
- mountainous watershed applications are extensive

WMFire + fire-effects:
- landscape fire spread
- litter/CWD fuel
- understory ladder fuels
- PFT/stratum mortality and biomass consumption
- postfire ecohydrologic feedback

## criterion 1: spatial cohort
Patch geography is excellent, but canopy strata are **vegetation layers/state objects**, not demographic age/size cohorts generated by recruitment.

판정: PARTIAL.

## criterion 2: understory + succession
Understory representation itself is strong:
- user-defined multiple canopy layers
- grass/shrub/tree vegetation parameter sets
- vertical light attenuation
- separate C/N pools and growth

그러나 current architecture에서 stratum identity/type은 worldfile input으로 정의된다.
Natural recruitment that creates new herb/shrub/tree cohorts and endogenous replacement of strata was not identified.

TEC events can:
- redefine strata
- redefine world state
- impose logging/fire/land-use changes

이는 external event control이지 autonomous demographic succession이 아니다.

따라서:
**explicit understory physiology = STRONG**
**endogenous demographic succession = WEAK**

## criterion 3: soil-geomorph coupling
VERY STRONG:
- patch soil state
- topography
- soil moisture
- saturation deficit
- explicit flow table
- lateral downslope water redistribution
- event-driven state/world redefinition
- current state can be exported

Geomorphic soil-depth remapping itself is still custom, but coupling architecture is friendly.

## criterion 4: watershed/topography
EXCELLENT.
RHESSys is purpose-built for watershed ecohydrology and has many mountainous watershed applications.

## criterion 5: time
STRONG for physiology/ecohydrology:
- daily core processes
- some output/event infrastructure hourly

하지만 demographic recruitment/succession engine 자체가 없으므로 criterion 5 cannot rescue criterion 2.

## current verdict
**Do not use as primary vegetation succession engine.**

Potential role:
- hydrology/fire comparator
- coupling architecture reference
- if external demographic model is adopted, RHESSys-like spatial hierarchy and flow routing are useful design references

The model is especially valuable as evidence that:
mountain catchment + explicit understory + daily ecohydrology + fire can coexist computationally,
but it does not solve the required self-organized herb -> shrub -> tree demographic succession.
