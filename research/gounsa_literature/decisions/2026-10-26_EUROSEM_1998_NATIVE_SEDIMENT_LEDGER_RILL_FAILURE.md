# EUROSEM 1998 원본 유사수지 재검증: 세류 모드 전체 사면 수지 불합격

작성일: 2026-10-26. 대상: TheSoilman/EUROSEM 1998 공개 원본 Fortran 및 호환성 보정 실행기. 이번 실험에서는 유사수송/침식 물리식을 변경하지 않고 수치 출력용 WRITE 명령만 삽입했다. 기본 GNU Fortran 컴파일 옵션에는 -finit-local-zero와 기타 원본 호환성 옵션이 들어가므로 무보정 1998 실행파일이라고 부르지 않는다.

## 연구 목적
2026-10-25 LAI 민감도 729회 분석이 부적절했던 이유를 감사한 뒤, 2026-10-26 원본 Fortran의 독립적인 유사수지와 세류 침식 전달을 검증한다. 사용자의 최우선 조건은 실제 식생 상태 수관과 2D 지표유출 침식이며, EUROSEM은 1D 연결 사면요소 방식이므로 이 실험이 통과하더라도 2D 주 엔진 선정 근거가 될 수 없다.

## 원본 코드에 존재하는 기존 수지식
eplanel.for 873–924행은 직접 원본 유사수지 확인 코드를 제공한다. 원본 세류간 수지는 inrlbal = sumqirr + sumdir + suspir 이고, 원본 세류 수지는 rillbal = stout + sumdrl + susprl - sedin 이다. 네 항목은 유사 유출, 순침식/퇴적, 부유유사 저장, 외부 유입과 관련된다. sumdir 및 sumdrl이 음수이면 순침식이다. 이전에 원본에 유사수지 계측 코드가 없다고 한 진술은 틀렸다.

## 실제 모의 설계 및 구현 경로
- 개발자 공개 Fortran을 CI 실행 중 원본 저장소에서 다시 취득한다. 진단 출력 외의 과정식은 변형하지 않았다.
- 원본 예제에서 단일 사면 100m x 145m, 경사 0.85, 토양 포화침투 5mm/h, 식생높이 입력 120cm, 피복률 0.9, 차단저류용량 DINT 1.5mm, EROD 0.9g/J, 60분 강우+28분 회복기간. 해당 계수는 고운사 실측값이 아니다.
- 강우강도 30, 50 mm/h; dt=60,30,15초; 세류 없음 또는 15개 세류, 각 폭 0.25m/깊이 0.02m; Govers MCODE0 및 Everaert MCODE1. 총 24회.
- 원본의 매 시간단계 Q 및 CT를 계측하고, 외부 Python으로 0.5*(Qnow*CTnow+Qprev*CTprev)*dt를 적분해 유출구 유사체적을 독립 재계산했다. 원본 SEDTOT/(RHOS*1000)과 비교했다.
- 원본 세류간 및 세류 토양 변화와 마지막 부유유사 저장량으로 전체 사면 잔차를 계산했다. 내부 세류간->세류 유사이동은 검사체적 내부 순환이므로 전체 사면 수지에서 상쇄한다.
- 별도 재시험에서 original eplanel.for의 세류 계산 CALL SEDCOM에 실제로 전달되는 QLRAV,CLAT,XL,DEPNO,dt를 직접 계측하고 이를 별도로 적분해 세류간 유사유출량과 비교했다.

## 판정
- **원본 EUROSEM 세류 포함 유사 질량보존 검증 FAIL.** 세류와 세류간 결합을 포함한 현 상태로는 고운사 침식 지형발달에 사용하지 않는다.
- **원본 EUROSEM 세류 없는 1D 계산은 일부 조건 통과.** 특히 15초 조건 네 사례가 0.1% 이내이고 원본 유사배출 시간간격 수렴도 확인됨. 이는 한정된 조건의 보조 수관/침식 과정 벤치마크를 허용할 수 있다는 뜻이지 고운사 전체 모형 채택은 아니다.
- EUROSEM은 원본에 LAI 동적 수관저류 상태량이 없으며 과거 LAI.PAR은 실험 포크의 새 coupling이다. 원본은 genuine 2D 공간 사면도 아니다.
- 원본 세류 질량 불일치를 임의 보정계수로 숨기지 않는다. 세류 내부 유사재고와 bed 변경, 외부 유사를 분리 추적해 원인을 찾기 전에는 해당 결과를 물리적 정확도나 현장침식량으로 해석하지 않는다.
