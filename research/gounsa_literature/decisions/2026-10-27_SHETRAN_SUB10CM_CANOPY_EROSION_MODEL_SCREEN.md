# 2026-10-27 고운사 cm급 단일 침식모형 추가 판정

## 질문
드론 LiDAR/TLS가 cm급인데 SHETRAN은 4m에서 실행했으므로, **10cm 이하에서 LAI 관련 동적 수관차단 + 2D 지표유출 + 강우 및 유수박리 + 격자간 유사수송/퇴적**을 하나의 공개 원본모델 안에서 구현/검증한 사례가 있는가?

## 원칙
- **고정 선호:** 단일모델 사용, 식생의 LAI/수관저류·수관배수/직접우와 적하 구분 필수, 2D 지표유출과 국지 퇴적 필수, 원본 공개 및 실행/유사수지 검증 필수.
- 초고해상도 *DEM 관측/DoD*와 똑같은 격자에서 *물리모형*을 푸는 것은 다르다. 각자 검증.

## 후보 검증
1. **SHETRAN 4.7.2**: GitHub upstream cf9cd540. SHETRAN 원본 `src/core/sglobal.f90`: NXEE=1000, NYEE=1000, NELEE=250000 최대(채널과 하안 포함), LLEE=50. 0.648ha = 6480m²의 10cm 균일 래스터는 육상격자만 `648000`개라 NELEE 하드캡 초과. 5cm는 `2592000`개, 더 심각함. **배열상한 코드 수정은 가능성 있지만 실험으로 확인하지 않음**. 10cm에서 X/Y 한 방향이라도 100m보다 크면 NXEE/NYEE도 초과. 가상 4m native 성공은 10cm 계산성공 근거 아님. 장점: ET/OC/VSS/SY 원본 물리식 실험 검증, canopy leaf-drip 별도 구현. **10cm 시험 우선**.
2. **OpenLISEM 7.5.2**: 원본 개발자 GitHub README는 2017년부터 1cm 격자 시험(2m²)이라고 쓰지만 이는 **1cm 강우/유사 수렴 통과 검증 논문 또는 0.648ha 실험이 아님**. 참고 URL https://github.com/vjetten/openlisem. 이미 고운사 native 2026-10-26 5m 1ha, 12회 시간간격 변경(5/10/20초)의 유사량이 수백~수천 배 변동, 노출 토양 재고 상한 위배 판정 **NO-GO**: [기존 검증](2026-10-26_OPENLISEM_752_NATIVE_2D_STABILITY_FAILED.md). 1cm 개발자 메모만으로 재채택 불가.
3. **PSEM_2D (Nord & Esteves 2005)**: https://doi.org/10.1029/2004WR003690 . **실제 5cm 격자**에서 비정상 2D SWEs, Green-Ampt, 강우/유수박리 및 퇴적 모의/인공강우 비교. **논문 §4.2 수관차단/식생 조도 전혀 고려하지 않는 나지 전용 명시**. 자연 75m² 사면은 실측 지형간격 20cm, 실측 유사량 없음. 원본 공개 전체코드 확인 안 됨. 단일 canopy+침식 조건 탈락. [개별 논문](../papers/2005_Nord_Esteves_PSEM2D_5cm_BareSoil.md).
4. **SMODERP2D**: https://storm-fsv-cvut.github.io/smoderp2d-manual/ . interception LAI/최대 저장, 2D 면상류/세류 수문, 침식 위험 모의, 공개소스. 그러나 공식 requirements https://storm-fsv-cvut.github.io/smoderp2d-manual/requirements.html 에 **권장 cell 2–20m**로 명시, 세류 폭 미만 cell 수리표현 부적절. 고운사 10cm 단일모델 검증 근거 부족.
5. **고해상도 식생주변 유사이송 연구**: Li et al.(2023, WRR, 10.1029/2021WR031896)에서 고정된 수생식생 주변에 최소 셀 폭 0.011m과 0.024m를 사용, 흐름/유사이송/바닥변형을 모의. 다만 **빗물의 수관차단, 강우침투 및 강우로 인한 원토양 박리가 목적이 아닌 수로 유입조건**이므로 탈락.
6. **LiDAR 자체 연구**: https://www.sciencedirect.com/science/article/pii/S2095633917300084 , 1/2/5/8/10/15/20/30cm DoD 기반 세류침식 관측에서 10cm와 1cm 사이의 검출된 침식/퇴적 면적 큰 차이. 이 논문은 **수치 침식모델이 아니라 DEM 지형변화 측정연구**임.

## 가장 중요한 판정
- **현재까지 10cm 이하 + 원본 LAI/수관저류·적하 + 2D 직접유수박리 + 유사수송·퇴적 + 실행 검증을 모두 충족하는 모델은 확인되지 않음**. 존재하지 않는다는 증명은 아님.
- 따라서 **기존 선정 주모델 SHETRAN은 유지**하고, 0.648ha 전역에서 10cm 래스터를 받아낼 수 있도록 static-cap 및 allocatable 메모리 구조를 우선 감사해야 함. 반드시 순정 원본/배열만 확장한 빌드와 동일 4m 입력의 bit-level 또는 허용 오차 검증, 수관물수지와 유사수지, 시간간격 및 4m→1m→0.5m→0.2m→0.1m 공간 수렴(가능한 자원 내), 경계 유사배출, 실제 DoD에 대해 확인.
- **이상적인 단일 수치모형 격자와 LiDAR 원자료 해상도는 같을 필요가 없다.** 최종 격자를 1m로 미리 정하지 않으며, 사용자의 cm급 공간신호를 잃지 않는지를 DoD/세류/식생패치 분석으로 판정한다.
- 10cm에서 DRAINA/PLAI/CLAI는 10cm 격자가 잎과 줄기의 개별 3D 적하 발원 위치를 직접 표현한다는 뜻이 아님. 서브격자 모델의 의미와 식생별 지면도달우 재분배 가정을 분리 검증해야 함.
