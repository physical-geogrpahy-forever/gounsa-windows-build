## Concrete new evidence and provenance
1. **DHSVM source reality:** GitHub API listing `pnnl/DHSVM-PNNL/DHSVM/sourcecode` contains `InterceptionStorage.c`, `RouteSurface.c` and CMake list, but no erosion/sediment C filenames. `README.md` says default surface/subsurface D4 and optional D8. Doten 2006 source extension not present; do not substitute Stewart 2017 scientific integration into a new land model as the original compiled executable.
2. **TREX official docs** https://www.engr.colostate.edu/~pierre/ce_old/Projects/TREX%20Web%20Pages/TREX-Overview.html ; source and test menu https://www.engr.colostate.edu/~pierre/ce_old/Projects/TREX%20Web%20Pages/TREX-Home.html ; real Japanese forest and Korean Nakdong tributary adaptation https://www.engr.colostate.edu/~pierre/ce_old/Projects/TREX%20Web%20Pages/TREX-Research.html ; Velleux 2008 DOI 10.1016/j.scitotenv.2008.05.053. Original sample ZIP bytes not acquired.
3. **Iber source vs executable distinction:** Cea, L., García-Feal, O., Nord, G., Piton, G., & Legoût, C. (2024), Environmental Modelling & Software 179, 106098, DOI 10.1016/j.envsoft.2024.106098 validates rainfall+runoff multiclass physics and field Pradel/Alps. **Research Data Gouv release explicitly 'Iber+ executables (V3.2b)'**, Windows/Linux at https://doi.org/10.57745/UFEK4L. No claim of full published C/Fortran source.
4. **SMODERP2D:** https://github.com/storm-fsv-cvut/smoderp2d `core/vegetation.py`, `processes/rainfall.py` LAI fraction, potential interception; no complete erosion mass equations found in inspected `processes/` structure; do not infer from name 'erosion-control'.
5. **SHETRAN:** historic final decision https://github.com/physical-geogrpahy-forever/gounsa-windows-build/blob/main/research/gounsa_literature/decisions/2026-10-26_SHETRAN_FIT_FOR_PURPOSE_REASSESSMENT.md remains binding.
