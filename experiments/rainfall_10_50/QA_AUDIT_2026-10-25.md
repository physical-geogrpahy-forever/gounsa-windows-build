# 10–50 mm/h rainfall sensitivity: native-source execution and scientific QA (2026-10-25)

## Scope and verdict

Five events: 10, 20, 30, 40, 50 mm/h applied continuously for 1 hour. These are **rainfall intensity**, not 10–50 mm/h with arbitrarily changing durations. Intended Gounsa outcomes: canopy interception, free throughfall, canopy drip, stemflow, infiltration/preferential flow, surface runoff, rainfall- and flow-driven detachment, sediment export and deposition. **Those coupled outcomes were NOT produced and NO calibrated Gounsa soil loss curve exists.** This is an execution-and-validation audit of publication-source code and example inputs, not a completed site simulation.

The engine sources are downloaded and built on GitHub Actions. The physical equations are not substituted by handmade runoff models. This branch is experimental and intentionally not merged into main.

## Source provenance

- SWEHR: `csdms-contrib/swehr` commit `4e6f783f335ac6dc1c116ef0d516c2f3d1b911e2`, native C.
- EUROSEM: `TheSoilman/EUROSEM` commit `8652944da6e1e8436495aa0c08765e2399830dd7`, native legacy Fortran 77.
- HETEROFOR 1.0 source: `jonard76/HETEROFOR-1.0` published Java/CAPSIS code archived as 7z. Not executed without plot/tree/soil inputs and CAPSIS runtime.
- Charlier et al. (2009) MHYDAS plot runoff, Xiao (2000/2007), Apip et al. (2008), Rutter (1975), Gash (1979): research equations and published processes discussed separately; no verified runnable original numerical code and published input decks executed here.
- Other previously discussed codes (OpenLISEM, WEPP, SHETRAN): not executed in this experiment and MUST NOT be represented as having generated results.

## Native-source runs and failure audit

### SWEHR original 3×51 published example: all 5 rain scenarios completed

- `input.txt` from source is preserved except duration and rainfall; 10 runs with a=ad=0 (published source example) and a=ad=1 (exploratory test) completed with return code 0.
- Published C source initializes `KS[i][j]=0` in its example, so this test cannot demonstrate infiltration or preferential stemflow. No explicit localized stemflow is present.
- Native run reports **maximum elevation change ≈5.88 m** after the 1-hour rainfall scenarios, even a=ad=0, and **mean final water depth ≈36.45 mm at 10 mm gross rainfall**. The relationship between final water and rain is inconsistent with a simple closed water balance and requires boundary-state audit. The experiment is thus **physically invalid as erosion sensitivity evidence**.
- This was a source-execution test, not a validated Gounsa sensitivity result.
- Original full example run: https://github.com/physical-geogrpahy-forever/gounsa-windows-build/actions/runs/40202181315

### SWEHR cropped example 3×7: do not use as scientific evidence

- First cropped runs were invalid because published C uses hard-coded measurement points at y=10,20,30,40,50, outside the truncated domain. The published source was subsequently patched **only to relocate diagnostic probe points and the second outlet** (not the physics), but large water/bed anomalies persisted; crop itself cannot represent source benchmark boundary conditions.
- In addition a=ad=1 were exploratory and not the original test values. All numbers/figures from this cropped experiment are **retracted**.
- Probe patch audit: https://github.com/physical-geogrpahy-forever/gounsa-windows-build/actions/runs/40203093894

### EUROSEM published F77 example: source builds but complete five-point sensitivity NOT verified

- The legacy files include Ctrl-Z DOS EOF markers and fixed-form statements with trailing comments. Converting to 72-column fixed format and dropping Ctrl-Z sufficed for GNU Fortran compilation, without editing model equations.
- Example uses 2 unconnected planes (warning: element 1 not connected to downstream), slope `S=0.85`, vegetation `COVER=0.15` and other example values, **not Gounsa vegetation or hydrology**.
- For each event, original `test.pcp` hyetograph was set to 0 at 0 min, 10..50 mm at 60 min, and same cumulative depth at 100 min; `TFIN` in original `test.par` is 88 minutes (includes 28 min recession).
- Across repeated workflows on **same source/input**, some runs gave process exit 0 plus nonempty static/dynamic outputs, whereas others gave process exit 0 **with zero-byte output** or exit -11 segmentation fault. Thus run status alone is not numerical success and repeatability is not established.
- In one EUROSEM 20 mm/h run, static output reported rainfall 19.865 mm, infiltration 19.87074 mm, runoff 0.00020 mm, global volume balance error −0.0299%, gross interrill erosion 349.739 kg in element 1 / 34.168 kg in element 2 and net erosion 1.511 kg for each element. This is only one **unreplicated original example output**; not a rain-intensity response curve or Gounsa soil loss value.
- 50 mm/h segfaulted in all recorded runs.
- Run (some native output): https://github.com/physical-geogrpahy-forever/gounsa-windows-build/actions/runs/40203613881

## Process ownership and remaining boundary conditions

| Published model | Canopy interception, throughfall, stemflow | Infiltration / surface runoff | Erosion / deposition | Current status |
|---|---|---|---|---|
| Rutter, Gash | yes, canopy partition (versions vary) | no | no | Equations identified, no independent original-run |
| Xiao et al. 2000 | yes, explicit canopy/tree geometry | no full hillslope erosion | no | Published process only |
| Xiao et al. 2007 | yes | infiltration and runoff by landcover | no | Published process only |
| Charlier et al. 2009 | stemflow redistribution into zones | verified runoff study | no | Published process only |
| HETEROFOR de Wergifosse et al. 2020 | yes, hourly forest/soil water | soil water but no hillslope surface runoff | no | Source identified, no executable scene |
| EUROSEM 1998 | canopy components and NR | yes, routing via hillslope/channel elements | interrill/rill and deposition | native compiles, runs unreliable |
| Apip et al. 2008 | DT+SF+LD then NR | yes, distributed 1D routing | rainfall/flow-driven erosion | no original run |
| McGuire et al. 2016 SWEHR | no individual stemflow localization | Green-Ampt and genuine 2D | multi-size erosion and deposition | native runs, QA reject |
| Li and Tian 2026 | drop KE of throughfall components | no | drop KE forcing only | equations only |

**What is needed for a meaningful full 10–50 mm/h sensitivity:**
(1) vegetation-specific canopy capacities, individual SF and TF and leaf-drip KE, driven by actual tree/grass structure;
(2) spatially resolved soil K_s and macropore paths around stems, and initial soil moisture;
(3) same Gounsa DEM/domain, outlet and boundary conditions for each model;
(4) distinct published equations and clearly marked *new coupling* for spatial redistribution of SF into 2D runoff/erosion;
(5) runoff water balance, total sediment budget, baseline reproduction and repeatable parameter runs before reporting any erosion comparisons.
