# v1.7 뿌리 깊이 모듈 첫 실행 결과

실행: GitHub Actions run 43806452022, 브랜치 `lorica-treed-v1.7-root-depth`, 결과는 results 브랜치 `runs/43806452022_v17rd`.
시험 기후는 v1.6과 같은 합성 강우(매일 거의 일정한 비)이며 고운사 관측값이 아니다.

## 확인된 것

1. **모듈을 끈 상태(`off`)는 v1.6 A 조건과 같다.** 연도별 래스터 816개가 해시까지 같고, `annual_state.csv`, `cell_timeseries.csv`, `TREED_rootcohesion_timeseries.csv`, `slide_stage_ledger.csv`, `soil_layers.csv`도 같다. (`treed_restart_traits_by_cell.csv`만 다른데, v1.6 A 쪽이 당시 덤프 오류로 비어 있었기 때문이다.)
2. **모듈을 켠 두 조건 중 A_rd는 통과했다.** 질량 폐합 1.5e-15, 교환 오차 5.0e-7 m.
3. 단일 셀 시험에서 Guswa(2008) 식 12의 극한(저장 0, 저장 무한대, W가 1 위아래, 단조 증가)을 통과했다.

## 확인된 문제

1. **B_rd는 실패했다.** 사건 해(4년)에 산사태가 0건이었다. 원인은 뿌리 응집력이 낮아진 것이 아니라 오히려 이쪽 문제다. 사건 해 평균 응집력이 A_off 3.45 kPa, A_rd 2.53 kPa로, v1.6 설계가 응집력 ±10% 범위에서만 3건을 보장하는데 그 범위를 벗어났다. 설계 문제이지 모듈 오류로 보지 않는다. 다만 이 비교는 같은 조건의 반복이 아니므로 아직 단정하지 않는다.
2. **최적 뿌리 깊이가 탐색 하한(0.05 m)에 붙었다.** 토심 1 m인데도 `z_opt`가 전 셀, 전 연도에서 0.05 m였고 `z_r`은 0.455 m에서 34년 뒤 0.076 m로 줄었다. 이 시험 강우는 월 내내 하루 2 mm 안팎이라 건조 기간이 없다. 저장이 몇 mm만 있어도 비를 다 쓰므로 깊은 뿌리의 편익이 0이고, 비용만 남는다. 모델이 맞게 답한 것이며, 이 시험 설계로는 뿌리 깊이 형질을 시험할 수 없다는 뜻이다.
3. **1년차에 식생이 0이 된다.** 비용 146.1 g C m-2 yr-1 per m(Guswa 표 2)를 초기 `z_r` 0.5 m에 곱하면 순탄소이득이 -83.5에서 -164로 내려가 TREED의 높이 판정 기준(-80)을 넘는다. 2년차부터는 형질이 움직여 회복한다. 이 비용값은 한국 실측이 아니고, 결과를 크게 좌우한다.

- 비용 계수는 14.0(Guswa 표 1)과 146.1(표 2)을 모두 돌려 민감도로 보고한다. 하나를 골라 맞추지 않는다.
